DirSnap - Directory Structure Visualization Tool
==============================================

Installation:
1. Right-click on installer.bat and select 'Run as administrator'
2. Follow the prompts to install DirSnap

Usage:
- Double-click DirSnap.exe to run the application
- Right-click on any folder and select 'Open with DirSnap'

Uninstallation:
1. Navigate to your DirSnap installation folder (default: C:\Program Files\DirSnap)
2. Right-click on uninstaller.bat and select 'Run as administrator'
3. Follow the prompts to uninstall DirSnap

Troubleshooting:
- If the context menu entry doesn't appear, try reinstalling or manually running install_context_menu.bat as administrator
- Make sure you're running the installer as administrator
