# Globule Project Wiki: Home

This wiki serves as the central knowledge base for the Globule project, a revolutionary endeavor to build a semantic operating system layer that understands context and meaning, moving beyond traditional file and folder organization.

## 1. Project Vision & Overview

Globule aims to fundamentally change how humans interact with computers by creating a system where every input is captured, semantically understood, and becomes part of a queryable, interconnected knowledge graph. The ultimate goal is a "Semantic OS" where computers understand *why* and *how* things connect, not just *what* happened.

The initial MVP ("Ollie") focuses on a local-first CLI and TUI application that allows users to frictionlessly capture thoughts, process them with dual-track AI (embeddings + LLM parsing), store them intelligently, and then retrieve and synthesize them into structured documents.

## 2. Core Principles

The project is guided by several foundational principles:

*   **Capture First, Organize Never:** Optimize for frictionless input; AI handles all organizational complexity.
*   **Semantic Understanding Over Hierarchical Storage:** Information is connected by intrinsic meaning, not rigid folder structures.
*   **AI as a Collaborative Partner:** AI suggests, assists, and automates, but the user remains in control.
*   **Progressive Enhancement Architecture:** Build a simple, valuable core that can evolve without disruptive rewrites.
*   **Privacy-First, Hybrid-by-Choice:** Local processing by default; cloud features are opt-in.
*   **Modular and Pluggable Pipeline:** Components are abstract interfaces for future extension.

This wiki is organized to mirror the architectural components of the Globule system itself, grouping related documents by subject matter. Files are numbered to ensure consistent ordering, and a clear naming convention is used for clarity.

For navigation, please use the sidebar on the right (or left, depending on your GitHub Wiki configuration). It contains links to all documents.

## 3. Key Concepts

*   **Globule:** The atomic unit of information in the system, representing a captured thought or input.
*   **Semantic Understanding:** The ability of the system to grasp the meaning, context, and relationships between globules using AI.
*   **Dual-Track Processing:** The parallel use of semantic embeddings and LLM parsing to understand input comprehensively.
*   **Progressive Discovery:** The system's ability to surface relevant information as the user explores their knowledge base.
*   **Schema:** User-defined YAML files that encode specific workflows and data structures for different types of information.
