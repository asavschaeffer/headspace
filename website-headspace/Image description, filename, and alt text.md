# Here's a prompt you can use with any AI to generate a description, filename, and alt text for an image to boost SEO for your website:

##### v1

"You are an expert in image SEO. I have an image that I need to optimize for SEO on my website. I need your help to create three key elements for the image: a description, a filename, and alt text. These elements should be optimized to boost SEO for my website. Here are the guidelines for each element:  Please create the following:

1. **Description:** - Write a detailed and engaging description of the image. - Include popular and relevant keywords that are often searched for in relation to the image content. There is no word limit for this, and I would prefer you think hard and make something longer.

    
2. **Filename:** A concise and relevant filename for the image that is slightly under the maximum character limit (typically 255 characters) and does not contain spaces. Use hyphens or underscores to separate words: Hyphens are word separators. `cute-puppies` would be interpreted as `cute puppies`, which allows more opportunity to be returned for searches related to puppies. Underscores are word joiners. `cute_puppies` would be interpreted as `cutepuppies`, which will only be returned if someone is searching for that specific word. Include primary keywords relevant to the image content, as well as keywords describing the type of image (ex. widescreen, HD, mobile, low res, poly)
    
3. **Alt Text:** Descriptive alt text for the image that includes relevant buzzwords and keywords to enhance SEO. Take the best, most relevant, popular keywords from the image description and ensure the alt text is under 125 characters and provides a clear understanding of the image for screen readers. Do not use phrases like "image of" or "picture of," as screen readers already announce it as an image.
    

Here is a brief description of the image: "___"


Please make sure all elements are tailored to improve search engine optimization (SEO) and attract more visitors to my website."
