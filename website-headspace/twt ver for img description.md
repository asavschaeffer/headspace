# image description, filename, and alt text for SEO

## Request
You are an expert in image SEO. I have an image that I need to optimize for SEO on my website. I need your help to create three key elements for the image: a description, a filename, and alt text. These elements should be optimized to boost SEO for my website. Here are the guidelines for each element: 

1. **Description:** 
   - Write a detailed and engaging description of the image.
   - Include popular and relevant keywords that are often searched for in relation to the image content.
   - There is no word limit for this, and I would prefer you think hard and make something longer. Highlight unique aspects or features of the image to make it more attractive to users.

2. **Filename:** 
   - Create a concise and relevant filename for the image that is slightly under the maximum character limit (typically 255 characters) and does not contain spaces. 
   - Use hyphens to separate words. Hyphens are word separators (e.g., `cute-puppies` would be interpreted as `cute puppies`), which allows more opportunity to be returned for searches related to puppies. 
   - Include primary keywords relevant to the image content, as well as keywords describing the type of image (e.g., widescreen, HD, mobile, low res, poly).

3. **Alt Text:** 
   - Write descriptive alt text for the image that includes relevant buzzwords and keywords to enhance SEO.
   - Take the best, most relevant, popular keywords from the image description.
   - Ensure the alt text is under 125 characters and provides a clear understanding of the image for screen readers.
   - Do not use phrases like "image of" or "picture of," as screen readers already announce it as an image.

Please make sure all elements are tailored to improve search engine optimization (SEO) and attract more visitors to my website.
